## 2026-10-16：CUDA XGBoost 传统模型基线

### 任务与范围

用户要求先训练传统模型，并明确使用本机 CUDA/GPU。因当前没有 PET 实测抗菌标签，本次建立同一论文 A08 的非 PET PVA/木质素碳点膜回归基线，未训练或宣称得到 PET 配方预测模型。

### 数据与方法

- 从抗菌长表筛出 16 条明确数值观察，涉及 3 个膜添加水平、1 个碳点合成样品、1 篇论文。
- 用 100−存活率统一可转换的端点；排除重复派生行、其他论文/材料层级以及原库标记不适用于普通回归的零存活行。
- 输入为碳点添加百分数、接触时间、光照与菌种。原文 ID、配方 ID及制备后表征不作为输入特征。
- 固定参数 XGBRegressor：120 轮、深度 2、学习率 0.05、L2=10，不搜索超参数。
- 采用按膜配方完整留出的三折验证，与训练折均值基线使用相同划分；编码器只在训练折拟合。

### GPU 与结果

- NVIDIA GeForce RTX 4080 Laptop GPU，12,282 MiB 显存，驱动 617.14。
- XGBoost 3.4.1 CUDA 构建；每折与最终拟合检查 device=cuda:0 和 grow_gpu_hist，禁止静默 CPU 回退。
- 折外 MAE 17.598 个百分点、RMSE 21.007 个百分点、合并 R²=0.376。
- 均值基线 MAE 25.238 个百分点；剔除两个原文 100% 端点的敏感性分析 MAE 16.243、R²=0.296。
- 误差仍较大，只有三个分组，结果不能当作外部泛化精度或 PET 最优配方依据。

### 保存与验证

- 保存训练管线、原生 Booster JSON、模型元数据、依赖锁定文件、实际训练数据、排除原因、逐条折外预测、分折指标及验证图。
- 六项测试通过，覆盖标签转换/去重、按配方分组、CUDA 设备、零存活处理及输入域限制。
- 重新加载模型的预测命令通过。预测入口拒绝 PET、其他材料层级、未知菌种/光照、非有限数值以及范围外输入。
- 输出位于 output/training/literature_pva_xgb_cuda_v1/，模型位于 models/literature_pva_xgb_cuda_v1/。
- Python 训练依赖安装在项目专用 .venv-ml，未修改原 .venv 或 CUDA 系统环境。
